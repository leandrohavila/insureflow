## Princípios

1. **Navy** = autoridade (sidebar, texto, header CRM dark).  
2. **Ouro** = valor e ação (CTA portal, item ativo, preço).  
3. **Marfim/Paper** = fundo light e placa da logo.  
4. **InsureFlow** não entra na paleta de marca — só crédito tipográfico.  
5. Densidade operacional do CRM **preservada** (grid 4px, body 15px).

## Referências de produto (Premium Finance)

- BTG Pactual Digital — navy, tipografia sóbria, dados densos  
- XP Empresas — hierarquia clara, KPIs em destaque  
- HubSpot Enterprise — pipeline legível, sidebar permanente
