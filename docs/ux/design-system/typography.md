# Tipografia — Grupo Ávila

---

## Famílias

| Papel | Família | Onde |
|-------|---------|------|
| **Marca** | Logo PNG/SVG oficial | Sidebar, login, portal header — **nunca** Didot simulada no CRM |
| **Display portal** | Playfair Display | H1 home, título imóvel, hero |
| **UI CRM** | Geist Sans (existente) | Toda interface operacional |
| **UI portal body** | Source Sans 3 | Parágrafos, formulários, filtros |
| **Meta / caps** | Geist ou Source Sans | Labels 10–11px, tracking 0.12–0.16em |
| **Mono** | Geist Mono | Nº apólice, protocolo, código imóvel |

| Elemento | Tamanho | Peso | Tracking |

| Section title | 16–18px | 600 | -0.02em |
| Body | 15px (`0.9375rem`) | 400 | -0.011em |
| Table header | 12px | 500 | 0.08em uppercase |
| KPI value | 20–24px | 600 | -0.03em |
| KPI label | 10px | 500 | 0.08em uppercase |
| Sidebar unit | 15px | 600 | normal |
| Sidebar sub | 10px | 500 | 0.14em uppercase |
| Powered by | 10–11px | 400 | 0.04–0.06em |

## Referências Premium Finance

- Títulos contidos, sem display exagerado no CRM  
- Números financeiros com peso 600–700 e tabular-nums onde aplicável  
- Caps sparingly — só labels de seção e unidade (CORRETORA · SEGUROS)
