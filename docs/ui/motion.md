# Motion

Motion deve reforçar foco e orientação, não decorar a interface.

## Tokens

- `motion.fast`
- `motion.normal`
- `motion.slow`
- `motion.hover`
- `motion.modal`
- `motion.drawer`
- `motion.toast`

## Regras

- Não usar durações inline em componentes novos.
- Respeitar `prefers-reduced-motion`.
- Animações de tabela/lista devem ser discretas.
- Modais e drawers devem usar os mesmos tempos oficiais.
