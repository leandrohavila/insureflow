# Icons

Ícones usam Lucide e são mapeados por categoria.

## Categorias

- AppIcon: marca e chrome global.
- ModuleIcon: módulos de navegação.
- EntityIcon: entidades de negócio.
- StatusIcon: estados semânticos.
- ActionIcon: ações.

## Regra

Novos ícones devem entrar em `apps/web/lib/design-system/icons.ts`.
Páginas não devem escolher ícones arbitrariamente para conceitos existentes.
