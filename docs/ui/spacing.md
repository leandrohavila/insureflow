# Spacing

O InsureFlow usa uma escala compacta baseada no grid de 4px existente em
`--if-space-*`.

## Uso semântico

- `xs`: micro ajustes.
- `sm`: itens internos próximos.
- `md`: controles em toolbars.
- `lg`: cards e grupos de campos.
- `xl`: blocos internos.
- `2xl`: seções de página.
- `3xl`: ritmo vertical de página.

## Regra

Se um espaçamento novo parecer necessário, crie um token antes de usar valor
inline.
