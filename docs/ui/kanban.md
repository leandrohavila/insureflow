# Kanban

Kanban é padrão crítico para o CRM de negócios.

## Padrões

- Colunas com largura definida por tokens.
- Gap horizontal único.
- Header sticky e compacto.
- Cards densos, escaneáveis e acessíveis por teclado quando interativos.
- Drag overlay preserva largura e densidade do card.

## Regra

Não criar novos boards fora dos componentes oficiais KanbanBoard,
KanbanColumn e KanbanCard.
