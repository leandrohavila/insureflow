# Page Patterns

## List Page

PageContainer -> PageHeader -> StatGrid opcional -> FilterBar -> DataTable.

## Workspace Page

PageContainer -> PageHeader -> Toolbar -> Split workspace ou board.

## Form Dialog

Dialog -> FormLayout -> FormField -> footer actions.

## Placeholder

PageContainer -> PlaceholderPage -> EmptyState.

## Regra

Toda nova tela deve escolher um pattern antes de implementar componentes.
